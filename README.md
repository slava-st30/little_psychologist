# HoReCa Recruit

Сервис психологической оценки кандидатов для HoReCa-сферы. Два Telegram-бота: рекрутер создаёт кандидатов и получает отчёты, кандидат проходит поведенческое интервью по ссылке.

## Стек

- **Runtime:** Node.js + TypeScript
- **Framework:** NestJS
- **Bot:** grammY (Telegram Bot API)
- **DB:** MongoDB + Mongoose
- **LLM:** OpenRouter API (arcee-ai/trinity-large-preview:free)

## Структура проекта

```
src/
├── app/            # Корневой модуль NestJS
├── assessment/     # Логика оценки: сессии, промпты, конфиг вопросов
├── dialog/         # Два бота + DB-сервис + Mongoose-схемы
├── i18n/           # Текстовые строки (ru / en)
└── llm/            # Обёртка над OpenRouter API
```

## Запуск

```bash
npm install

# Разработка (.env.dev)
npm start

# Продакшн (.env.prod)
npm run start:prod
```

## Переменные окружения

```env
RECRUIT_BOT_TOKEN=        # Токен рекрутерского бота (@BotFather)
CANDIDATE_BOT_TOKEN=      # Токен кандидатского бота (@BotFather)
CANDIDATE_BOT_USERNAME=   # Username кандидатского бота (без @)
OPENAI_API_KEY=           # OpenRouter API Key
MONGODB_URI=              # MongoDB connection string
```

## Флоу

1. Рекрутер пишет `/create Имя Фамилия` → получает одноразовую ссылку на кандидатский бот
2. Кандидат переходит по ссылке → проходит 4 поведенческих вопроса
3. Если ответ слишком общий — бот задаёт уточняющий вопрос
4. После последнего ответа LLM генерирует отчёт
5. Рекрутер получает ответы кандидата + отчёт по 4-уровневой модели ПВК

## Команды рекрутерского бота

| Команда | Описание |
|---------|----------|
| `/create Имя Фамилия` | Добавить кандидата и получить ссылку |
| `/list` | Список кандидатов со статусами |
| `/candidate <номер>` | Отчёт по кандидату |
| `/remove <номер>` | Удалить кандидата |
| `/info` | Справка по боту |

## Статусы интервью

| Статус | Описание |
|--------|----------|
| ⏳ Не начал | Кандидат ещё не перешёл по ссылке |
| 🔄 В процессе | Интервью идёт |
| ✅ Завершил | Интервью пройдено, отчёт готов |
| ❌ Отменил | Кандидат нажал `/cancel` |

## Модель оценки

4-уровневая система ПВК (Зеер, Климов, Марков), шкала 1–5:

| Уровень | ПВК |
|---------|-----|
| I | Физическая выносливость и точность |
| II | Стрессоустойчивость и саморегуляция |
| III | Социальная перцептивность и эмпатия |
| IV | Этическая позиция и ценностная направленность |
