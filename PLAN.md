# HoReCa Recruit — Plan

## Сделано

- Два бота: рекрутерский (`RECRUIT_BOT_TOKEN`) + кандидатский (`CANDIDATE_BOT_TOKEN`)
- MongoDB: схемы `Candidate` + `Interview`, статусы pending / in_progress / completed / cancelled
- Одноразовые ссылки по токену (`/create Имя` → ссылка на кандидатский бот)
- 4 поведенческих вопроса + LLM-уточнение + LLM-анализ по модели ПВК
- Рекрутер получает ответы кандидата + отчёт
- Команды рекрутера: `/create`, `/list`, `/candidate`, `/remove`, `/info`
- Статическое меню у каждого бота
- i18n (ru / en)
- Деплой на Timeweb VPS (Ubuntu 24.04, pm2, MongoDB 8.0)

## Backlog

### 1. Мультипрофессиональные анкеты

Поддержка нескольких профессий (официант, бариста, кассир, бортпроводник и др.).

**Архитектура:**
- Общий каркас промпта (4-уровневая модель, шкала 1–5, формат вывода) — один на всех
- `ProfessionConfig` = вводная строка + 4 вопроса + поведенческие примеры по уровням I–IV
- В промпт вставляются примеры только выбранной профессии
- Рекрутер выбирает профессию при `/create`

**Что сделать:**
1. Создать тип `ProfessionConfig`
2. Перенести текущий официантский конфиг в эту структуру
3. Добавить 2–3 профессии
4. Сохранять `profession` в кандидате и пробрасывать в промпт

### 2. Inline-кнопки для рекрутера

- `/list` → кликабельный список кандидатов с кнопками [👁 Отчёт] [🗑] на каждого
- `/start` → кнопки [📋 Список кандидатов] [➕ Добавить кандидата]
- Кнопка "Добавить" требует state-машины (спросить имя следующим сообщением) или Grammy Conversations plugin

### 3. Деплой обновлений

- Пушить в `main` → `ssh` на сервер → `git pull` → `npm run build` → `pm2 restart`

## Дополнительные идеи

- **PDF-отчёт** — оформленный PDF для архива (`pdfkit` / `puppeteer`)
- **Голосовые ответы** — транскрипция через Whisper, анализ как текст
- **Нормирование по пулу** — percentile после накопления N кандидатов
- **Флаг фальсификации** — отдельное поле 🚩 в отчёте для рекрутера
- **Напоминания** — если кандидат начал и не завершил, бот пишет через 24 часа
- **Комментарий рекрутера** — финальный статус (принят / отклонён / на доп. собеседование)
- **Дашборд** — веб-интерфейс со списком кандидатов, фильтрами, баллами
- **Интеграция с HH.ru** — автоматически отправлять ссылку откликнувшимся
- **Экспорт в CSV** — выгрузка всех кандидатов за период
- **Blind hiring** — рекрутер видит баллы до имени
- **A/B тест вопросов** — сравнивать качество ответов на разные варианты вопросов
